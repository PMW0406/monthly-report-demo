# 월간 재무보고 대시보드 — 데모

월 1회 경영회의 재무보고를 웹 화면으로 만드는 도구의 **동작 데모**입니다.

**화면 보기 →** https://pmw0406.github.io/monthly-report-demo/

## 안내
- 여기 표시되는 **모든 수치·회사명·거래처명은 임의로 만든 가상 데이터**입니다. 실제 기업의 실적과 무관합니다.
- 화면 구성(메뉴·표·카드·차트)은 데이터 파일(JSON)이 정의하며, 코드에는 특정 회사나 항목이 들어있지 않습니다.
- 생성된 결과물은 **단일 HTML 파일**이라 인터넷·서버·설치 없이 더블클릭만으로 열립니다.

## 만드는 방법
1. 결산 자료(PPTX·XLSX)에서 표를 자동 추출 → 초안 JSON 생성
2. 초안에서 필요한 표만 정리
3. 빌드 → 단일 HTML 생성

도구 일체는 별도 비공개 저장소에서 관리합니다.
